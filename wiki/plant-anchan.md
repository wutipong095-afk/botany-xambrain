# อัญชัน (Butterfly pea) — สัณฐานวิทยาระดับชนิด 🌐

## สาระสำคัญ

อัญชันเป็น **ไม้เถาล้มลุก วงศ์ถั่ว (Fabaceae)** ที่เหมาะเป็นเคสเรียน "ดอกรูปดอกถั่ว (papilionaceous)" มากที่สุดในบรรดาพืชที่ใช้บ่อยในครัวไทย เพราะดอกใหญ่ เห็นกลีบทั้ง 3 ชุดชัด และมี **ลักษณะพิเศษคือดอกกลับหัว (resupinate)** ที่ทำให้ผู้เริ่มเรียนอ่านกลีบผิดตำแหน่งได้ง่าย

นอกจากนี้ยังเป็นสะพาน Layer S → U ที่ชัดเจน: **สีจากกลีบดอก (anthocyanin กลุ่ม ternatin)** เปลี่ยนสีตามความเป็นกรด-ด่าง จึงถูกใช้เป็นสีผสมอาหารและอินดิเคเตอร์ธรรมชาติ

## 1. Naming

| หัวข้อ | ข้อมูล |
|--------|--------|
| **ชื่อวิทยาศาสตร์** | *Clitoria ternatea* L. |
| **วงศ์** | Fabaceae (Leguminosae) วงศ์ย่อย Faboideae/Papilionoideae |
| **ชื่อไทย/พื้นเมือง** | อัญชัน (ภาคกลาง) · แดงชัน (เชียงใหม่) · เอื้องชัน (ภาคเหนือ) |
| **ชื่อสามัญ** | Butterfly pea · Blue pea |
| **รากศัพท์** | *ternatea* มาจากเกาะ Ternate (อินโดนีเซีย) ซึ่งเป็นแหล่งเก็บตัวอย่างต้นแบบ |

## 2. นิสัยการเจริญ (Habit)

- ไม้เถาล้มลุกอายุหลายปี **เลื้อยพันด้วยลำต้น (twining climber)** — ไม่มีมือเกาะ (tendril) แบบถั่วลันเตา
- ความยาวเถาถึงประมาณ 5 เมตร

## 3. ราก (Root) → [[root-morphology]]

- ระบบ **รากแก้ว (taproot)** พร้อมรากแขนง
- มี **ปมราก (root nodule)** ที่อยู่ร่วมกับแบคทีเรียตรึงไนโตรเจน — ลักษณะร่วมของวงศ์ถั่ว และเป็นเหตุผลที่อัญชันถูกใช้เป็นพืชคลุมดิน/ปุ๋ยพืชสด
- ตำราไทยและงานวิจัยใช้ทั้งราก ใบ ดอก และส่วนเหนือดิน

## 4. ลำต้น (Stem) → [[stem-morphology]]

- เถากลม เรียวเล็ก มีขนสั้นนุ่มปกคลุม
- ข้อและปล้องชัด · แตกกิ่งข้างจากตาที่ซอกใบ

## 5. ใบ (Leaf) → [[leaf-morphology]]

- **ใบประกอบแบบขนนกปลายคี่ (odd-pinnate / imparipinnate)** เรียงสลับ
- ใบย่อย **5–7 ใบ** รูปไข่–รูปรี ปลายมนหรือเว้าเล็กน้อย กว้าง **2–3.5 ซม.** ยาว **3.5–5.5 ซม.**
- แผ่นใบบาง ด้านล่างมีขนประปราย · มี **หูใบ (stipule)** ขนาดเล็ก และมี **หูใบย่อย (stipel)** ที่โคนใบย่อย
- **จุดสังเกต**: ใบย่อยจำนวนคี่และปลายสุดเป็นใบเดี่ยว — ต่างจากถั่วบางชนิดที่เป็นขนนกปลายคู่

## 6. ดอก (Flower) → [[flower-morphology]]

| หัวข้อ | ลักษณะ |
|--------|---------|
| **การออกดอก** | **ดอกเดี่ยว** ออกที่ซอกใบ (บางครั้งออกเป็นคู่) ก้านดอกมีใบประดับเล็ก |
| **สมมาตร** | สมมาตรด้านข้าง (zygomorphic) |
| **รูปดอก** | **รูปดอกถั่ว (papilionaceous)** — กลีบกลาง (standard/vexillum) 1 กลีบ ใหญ่ที่สุด · กลีบคู่ข้าง (wing) 2 กลีบ · กลีบคู่ล่างเชื่อมเป็นรูปท้องเรือ (keel) 2 กลีบ |
| **จุดพิเศษ** | **ดอกกลับหัว (resupinate)** — ก้านดอกบิดราว 180° ทำให้กลีบกลางที่ปกติอยู่ด้านบนมาอยู่ **ด้านล่าง** เวลาอ่านดอกจึงต้องเทียบจากขนาดกลีบ ไม่ใช่ตำแหน่งบน-ล่าง |
| **สี** | น้ำเงินเข้ม · ม่วง · ขาว มีแต้มสีเหลืองอ่อน–ขาวกลางกลีบกลาง |
| **ขนาด** | ดอกบานยาวราว 4 ซม. |
| **เกสรเพศผู้** | 10 อัน แบบ **diadelphous (9+1)** ตามแบบวงศ์ย่อย Faboideae |
| **พันธุ์ปลูก** | ดอกลา (กลีบชั้นเดียว) และดอกซ้อน (กลีบหลายชั้น จากการกลายของเกสรเป็นกลีบ) |

## 7. ผลและเมล็ด (Fruit & Seed) → [[fruit-seed-morphology]]

- ผลแบบ **ฝัก (legume/pod)** แบน ยาว **5–7 ซม.** ปลายมีจะงอยสั้น
- เมื่อแก่แห้ง **แตกตามตะเข็บ 2 แนว** แล้วบิดม้วน ดีดเมล็ดออก (จุดเรียนเรื่องการกระจายเมล็ดด้วยตัวเอง)
- เมล็ด **6–10 เมล็ด** ต่อฝัก รูปไต สีน้ำตาล–ดำ

## 8. Layer U — การใช้ประโยชน์

- **สีธรรมชาติ**: กลีบดอกมี anthocyanin กลุ่ม **ternatin** สีน้ำเงิน ใช้แต่งสีข้าว ขนม เครื่องดื่ม
- **อินดิเคเตอร์ pH**: น้ำอัญชันเปลี่ยนจากน้ำเงิน → ม่วง/ชมพู เมื่อเติมกรด (น้ำมะนาว) — ใช้สอนเรื่องรงควัตถุพืชได้ตรง ๆ
- **พืชคลุมดิน/อาหารสัตว์**: จากคุณสมบัติตรึงไนโตรเจน (§3)
- **ไม้ประดับ**: ปลูกซุ้ม รั้ว

## 9. Layer T — มุมแผนไทยและข้อควรระวัง → [[thai-herbal]] · [[herbal-taste-9]]

- ตำราพื้นบ้านใช้ **ดอก** (ปลูกผมและแต่งสี) และ **ราก** (กลุ่มขับปัสสาวะ บำรุงสายตาตามความเชื่อ)
- งานทบทวนของคณะเภสัชศาสตร์ ม.มหิดล ระบุว่าสารสกัดจากส่วนต่าง ๆ มีรายงานฤทธิ์ด้านความจำ ลดน้ำตาล ต้านอักเสบ **แต่หลักฐานส่วนใหญ่ยังเป็นการศึกษาในสัตว์ทดลอง** จึงยังไม่มีขนาดใช้ที่ยืนยันในคน
- **ข้อควรระวัง**: มีรายงานฤทธิ์ต้านการเกาะกลุ่มของเกล็ดเลือด — ผู้ใช้ยาต้านการแข็งตัวของเลือด (เช่น แอสไพริน วาร์ฟาริน) ควรระวัง

## Misconceptions ที่พบบ่อย

| ความเข้าใจผิด | ข้อเท็จจริง |
|----------------|--------------|
| กลีบใหญ่ที่อยู่ด้านล่างคือกลีบ keel | เป็น **กลีบกลาง (standard)** ที่กลับตำแหน่งเพราะดอก resupinate (§6) |
| อัญชันมีมือเกาะเหมือนถั่วลันเตา | เลื้อยด้วยการ **พันลำต้น** ไม่มีมือเกาะ |
| น้ำอัญชันเปลี่ยนสีเพราะเสีย | เปลี่ยนเพราะ **pH** ของสารที่เติมลงไป (anthocyanin) |
| ใบอัญชันเป็นใบเดี่ยวหลายใบ | เป็น **ใบประกอบขนนกปลายคี่ 1 ใบ** ที่มีใบย่อย 5–7 ใบ |

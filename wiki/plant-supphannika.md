# สุพรรณิการ์ / ฝ้ายคำ (Yellow silk cotton) — สัณฐานวิทยาระดับชนิด 🌐

## สาระสำคัญ

สุพรรณิการ์ (ฝ้ายคำ) เป็น **ไม้ต้นผลัดใบในวงศ์ Bixaceae อันดับ Malvales** — วงศ์ใหม่ของชุด monograph และเป็นคู่หูในไฟล์เดียวกับ **จั๋ง** ([[plant-chang]]) เพื่อใช้เทียบ **พืชใบเลี้ยงคู่ (dicot) ↔ พืชใบเลี้ยงเดี่ยว (monocot)** ให้เห็นภาพ

จุดเรียน 3 เรื่องที่โหนดก่อนหน้ายังไม่มี:

1. **ดอกสมมาตรตามรัศมี (actinomorphic) กลีบใหญ่ + เกสรเพศผู้จำนวนมาก + อับเรณูเปิดด้วยรูที่ปลาย (poricidal)** → กลไก **buzz pollination** (ผึ้งสั่นปีกเขย่าละอองเรณูออกจากรู) — กลไกใหม่ที่ต่างจากดอกก่อนหน้า
2. **ใบเดี่ยวแฉกแบบฝ่ามือ (palmately lobed) 5 แฉก** — รูปใบใหม่ (ตัดกับใบประกอบขนนก/ใบเดี่ยวขอบเรียบของโหนดก่อน) · อันดับ Malvales เดียวกับฝ้าย/ชบา
3. **ผลแคปซูลแตก + เมล็ดมีปุยฝ้าย (kapok-like floss) ปลิวตามลม** → ที่มาของชื่อ **"ฝ้ายคำ" (ฝ้ายสีทอง)** — สะพานชื่อ ↔ สัณฐาน ↔ การกระจายเมล็ด

## 1. Naming

| หัวข้อ | ข้อมูล |
|--------|--------|
| **ชื่อวิทยาศาสตร์** | *Cochlospermum regium* (Schrank) Pilg. (ตามใบงาน) |
| **วงศ์** | Bixaceae (อันดับ Malvales) — บางระบบแยกเป็น Cochlospermaceae |
| **ชื่อไทย/พื้นเมือง** | สุพรรณิการ์ · **ฝ้ายคำ** (ฝ้ายสีทอง) |
| **ชื่อสามัญ** | Yellow silk cotton · Yellow cotton tree |
| **รากศัพท์** | *Cochlospermum* จากกรีก *kochlos* (หอยขด) + *sperma* (เมล็ด) = เมล็ดรูปขด/รูปไต · *regium* = "อย่างราชา/สง่างาม" |

> ⚠️ **หมายเหตุ taxonomy (Botany Literacy)**: สุพรรณิการ์/ฝ้ายคำ ที่ปลูกทั่วไปในไทยหลายแหล่งระบุเป็น ***Cochlospermum religiosum* (L.) Alston** ส่วน ***C. regium*** เป็นชนิดถิ่นอเมริกาใต้ · ใบงานกลุ่มใช้ *C. regium* — เก็บไว้ตามแหล่งหลักและ **ตั้งเป็นข้อตรวจสอบชนิดภาคสนาม** (ดอก/ผล/ถิ่นปลูกช่วยแยก) → ดู [[plant-taxonomy]]

## 2. นิสัยการเจริญ (Habit)

- ไม้ต้น **ผลัดใบ** · กิ่งก้านคดงอ
- **ออกดอกช่วงทิ้งใบ** (ปลายหนาว–ต้นแล้ง) ทำให้เห็นดอกเหลืองทั้งต้นเด่นชัด — คล้ายพฤติกรรมของคูน ([[plant-khun]]) ที่ออกดอกพร้อมผลัดใบ
- ⚠️ ความสูง 7–15 ม. ในใบงานค่อนข้างสูงกว่าที่พบทั่วไป (มักเป็นไม้ต้นเล็ก 3–8 ม.) — ตั้งเป็นข้อตรวจสอบ

## 3. ราก (Root) → [[root-morphology]]

- ระบบ **รากแก้ว (taproot)** ตามแบบพืชใบเลี้ยงคู่ — จุดตัดกับจั๋ง ([[plant-chang]]) ที่เป็นรากฝอย/แตกกอ (monocot)

## 4. ลำต้น (Stem) → [[stem-morphology]]

- ลำต้นตั้งตรง เปลือกเรียบ สีเทา–น้ำตาลเทา · กิ่งคดงอ

## 5. ใบ (Leaf) → [[leaf-morphology]]

- **ใบเดี่ยว (simple)** รูปหัวใจ **แฉกแบบฝ่ามือ (palmately lobed) 5 แฉก** · เรียงเวียนสลับ
- ขอบเป็นคลื่น–หยักเล็กน้อย · ปลายแฉกแหลม · โคนรูปหัวใจ · **เส้นใบแบบฝ่ามือ (palmate venation)** · ผิวมีขนสั้นนุ่มด้านล่าง
- **จุดเทียบสำคัญกับจั๋ง**: สุพรรณิการ์ = ใบเดี่ยว **แฉกฝ่ามือ (lobed แต่ยังเป็นแผ่นเดียว)** · จั๋ง = ใบ **ประกอบฝ่ามือ/รูปพัด (แยกเป็นใบย่อยจริง)** → สอนความต่าง "แฉก (lobed)" กับ "ประกอบ (compound)"

## 6. ดอก (Flower) → [[flower-morphology]]

| หัวข้อ | ลักษณะ |
|--------|---------|
| **การออกดอก** | ช่อกระจะที่ปลายกิ่ง · ดอกใหญ่สีเหลืองสด กว้าง 6–9 ซม. |
| **สมมาตร** | **สมมาตรตามรัศมี (actinomorphic)** — ตัดกับดอกถั่ว (zygomorphic) ของอัญชัน/แค |
| **กลีบเลี้ยง/กลีบดอก** | อย่างละ **5 กลีบ แยกจากกัน** · กลีบดอกซ้อนเหลื่อม |
| **เกสรเพศผู้** | **จำนวนมาก** · **อับเรณูเปิดด้วยรูที่ปลาย (poricidal dehiscence)** |
| **เกสรเพศเมีย** | 1 ชุด · รังไข่ **เหนือวงกลีบ 3–5 คาร์เพล** · ออวุลจำนวนมาก · ก้านเกสรเรียวยาวโค้ง |

> **จุดเรียนสำคัญ (buzz pollination)**: อับเรณูที่เปิดด้วยรู (poricidal) จะไม่ปล่อยละอองเรณูง่าย ๆ ต้องอาศัย **ผึ้งสั่นกล้ามเนื้อปีก (sonication/buzz)** เขย่าเรณูออก — กลไกเดียวกับมะเขือ/กระเจี๊ยบ · เป็นสะพาน S → นิเวศวิทยาการผสมเกสร

## 7. ผลและเมล็ด (Fruit & Seed) → [[fruit-seed-morphology]]

- ผล **แคปซูล (capsule)** รูปไข่–ไข่กลับ ห้อยลงเมื่อแก่ · **แตกเป็น 3–5 ซีก (valves)** ตามจำนวนคาร์เพล
- เมล็ดรูปไต (คล้ายหอยขด) สีน้ำตาล จำนวนมาก · **มีขนยาวคล้ายปุยฝ้าย (floss/kapok-like)** หุ้ม → **กระจายโดยลม**
- ชื่อ **"ฝ้ายคำ"** มาจากปุยฝ้ายสีทองนี้ · อันดับ Malvales เดียวกับ **ฝ้าย (*Gossypium*)** และ **นุ่น (kapok)** ที่ก็มีเส้นใยหุ้มเมล็ด

## 8. Layer U — การใช้ประโยชน์

- **ไม้ประดับ**: ดอกเหลืองใหญ่สะดุดตา ปลูกในสวน/ริมถนน · ดอกซ้อนเป็นพันธุ์ปลูกยอดนิยม
- **เส้นใยจากปุยเมล็ด**: ใช้ยัด/ประดับได้เล็กน้อย (คล้ายนุ่นแต่ปริมาณน้อย)
- **สัญลักษณ์**: สุพรรณิการ์เป็นพรรณไม้/ดอกไม้ประจำจังหวัดหลายจังหวัด (เช่น นครนายก อุทัยธานี สุพรรณบุรี)

## 9. Layer T — มุมแผนไทยและข้อควรระวัง → [[thai-herbal]] · [[herbal-taste-9]]

- ตำรับพื้นบ้านใช้ดอก/ยาง/เปลือกในบางท้องถิ่น (กลุ่มบำรุง/แก้ร้อนใน — หลักฐานคลินิกจำกัด)
- **ข้อควรระวัง**: เนื่องจากมีความสับสนของชนิด (§1) การใช้เป็นยา/อาหารต้องยืนยันชนิดให้แน่ก่อน

## Misconceptions ที่พบบ่อย

| ความเข้าใจผิด | ข้อเท็จจริง |
|----------------|--------------|
| ใบแฉกฝ่ามือ = ใบประกอบ | สุพรรณิการ์เป็น **ใบเดี่ยวที่ "แฉก" (lobed)** ยังเป็นแผ่นเดียว ไม่แยกเป็นใบย่อยจริง (§5) |
| ปุยฝ้ายที่เมล็ด = ดอก/เชื้อรา | เป็น **ขนหุ้มเมล็ด (floss)** สำหรับกระจายตามลม (§7) |
| "ฝ้ายคำ" คือฝ้ายที่ปั่นด้ายได้ | คนละสกุลกับฝ้าย (*Gossypium*) แม้อยู่อันดับ Malvales เดียวกัน · ปุยน้อยและสั้นกว่า |
| อับเรณูปล่อยเรณูเองเมื่อดอกบาน | อับเรณู **เปิดด้วยรู** ต้องอาศัยผึ้งสั่น (buzz) จึงปล่อยเรณู (§6) |
| สุพรรณิการ์กับจั๋งเป็นพืชกลุ่มเดียวกัน | คนละกลุ่มใหญ่: สุพรรณิการ์ = **ใบเลี้ยงคู่** · จั๋ง = **ใบเลี้ยงเดี่ยว (ปาล์ม)** → ดูตารางใน [[plant-chang]] |

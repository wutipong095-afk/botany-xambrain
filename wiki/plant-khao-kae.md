# เขาแกะ (เอื้องเขาแกะ) — สัณฐานวิทยาระดับชนิด 🌐

## สาระสำคัญ

เขาแกะเป็น **กล้วยไม้อิงอาศัย (epiphytic orchid) วงศ์ Orchidaceae** และเป็นโหนดพืช **ใบเลี้ยงเดี่ยว (monocot)** ตัวแรกในชุด monograph — จึงใช้เป็นเคสเรียน "สัณฐานวิทยาที่กฎของไม้ยืนต้นทั่วไปใช้ไม่ได้" ได้ดีที่สุด

จุดเรียน 4 เรื่องที่หาไม่ได้จาก M1–M6:

1. **รากอากาศ (aerial root) ที่มี velamen** — รากที่ดูดน้ำจากอากาศและสังเคราะห์แสงได้
2. **การเจริญแบบยอดเดียว (monopodial)** — ต้นสูงขึ้นจากตายอดเดียว ไม่มีลำลูกกล้วย (pseudobulb)
3. **ใบเรียงสลับระนาบเดียว (distichous)** โค้งสลับซ้าย-ขวา → **ที่มาของชื่อ "เขาแกะ"**
4. **ดอกกล้วยไม้**: กลีบปาก (labellum) · เดือย (spur) · **เส้าเกสร (column/gynostemium)** ที่เกสรเพศผู้-เพศเมียเชื่อมเป็นชิ้นเดียว · ดอกกลับหัว (resupinate) แบบที่เทียบกับอัญชันได้ตรง ๆ ([[plant-anchan]] §6)

## 2. นิสัยการเจริญ (Habit)

- **กล้วยไม้อิงอาศัย (epiphyte)** เกาะบนเปลือกไม้ — ไม่ใช่กาฝาก ไม่ดูดอาหารจากต้นอาศัย
- เจริญแบบ **ยอดเดียว (monopodial)** — ตายอดเดียวยืดขึ้นเรื่อย ๆ แตกใบใหม่ที่ยอด ใบล่างทยอยร่วง
- **ไม่มีลำลูกกล้วย (pseudobulb)** — ต่างจากกล้วยไม้กลุ่ม sympodial เช่น หวาย (*Dendrobium*) ที่แตกหน่อข้างและสะสมอาหารในลำลูกกล้วย

## 3. ราก (Root) → [[root-morphology]]

- **รากอากาศ (aerial root)** ค่อนข้างยาวและใหญ่ อวบ กลม แตกจากลำต้นบริเวณข้อ
- ผิวรากหุ้มด้วย **velamen** — เนื้อเยื่อชั้นเซลล์ตายหลายชั้น ทำหน้าที่ **ซับน้ำและความชื้นจากอากาศ** อย่างรวดเร็ว และกันการสูญเสียน้ำ (แห้ง = ขาวเทา · เปียก = เขียวโปร่ง)
- **ปลายรากสีเขียว** มีคลอโรฟิลล์ → รากสังเคราะห์แสงได้ (จุดเรียน: หน้าที่ของอวัยวะไม่ตายตัวตามตำรา)
- **ไม่มีรากแก้ว** — ระบบรากฝอยตามแบบพืชใบเลี้ยงเดี่ยว เทียบกับรากแก้ว+ปมรากของอัญชัน [[plant-anchan]] §3

## 4. ลำต้น (Stem) → [[stem-morphology]]

- ลำต้นเดี่ยว **ตั้งตรง รูปทรงกระบอก ค่อนข้างเตี้ย** สูงประมาณ **10–25 ซม.**
- ปล้องสั้น ข้อถี่ — โคนกาบใบซ้อนหุ้มลำต้นจนแทบไม่เห็นเนื้อลำต้น
- ไม่มีเนื้อไม้ ไม่มีการเจริญขั้นที่สอง (ไม่มี vascular cambium) ตามแบบใบเลี้ยงเดี่ยว → ใช้ "เปลือกต้น" เป็นลักษณะวินิจฉัยแบบ [[plant-tabaek]] ไม่ได้เลย

## 5. ใบ (Leaf) → [[leaf-morphology]]

| หัวข้อ | ลักษณะ |
|--------|---------|
| **การเรียงตัว** | **เรียงสลับระนาบเดียว (distichous)** — 2 แถวซ้าย-ขวาในระนาบเดียว โค้งลงสลับกัน = **ลักษณะที่ให้ชื่อ "เขาแกะ"** |
| **โคนใบ** | เป็น **กาบ (sheath)** ซ้อนกันเป็นแผงหุ้มลำต้น |
| **รูปร่าง** | รูปแถบ (strap-shaped / linear) ปลายโค้งลง |
| **ขนาด** | ยาวประมาณ **10–20 ซม.** กว้าง **1.5–2 ซม.** |
| **เนื้อใบ** | หนา แข็ง เหนียว อวบน้ำ (leathery–succulent) — **บางกว่าชนิดอื่นในสกุลเดียวกัน** |
| **หน้าตัดใบ** | **พับเข้าหากันเป็นร่องลึกกลางใบ (conduplicate / deeply grooved)** — ทำหน้าที่เป็นรางรับน้ำลงสู่โคนกาบใบ |
| **ปลายใบ** | เว้าเป็น 2 แฉกไม่เท่ากัน (unequally bilobed / praemorse) — ลักษณะร่วมของเผ่าย่อย Aeridinae |
| **เส้นใบ** | **ขนานตามยาว (parallel venation)** ตามแบบใบเลี้ยงเดี่ยว |

## 6. ดอกและช่อดอก (Flower & Inflorescence) → [[flower-morphology]]

| หัวข้อ | ลักษณะ |
|--------|---------|
| **ชนิดช่อ** | **ช่อกระจะ (raceme)** ออกที่ซอกใบ |
| **ทิศช่อ** | **ตั้งขึ้น (erect)** รูปทรงกระบอก ดอกเบียดกันแน่น — **จุดวินิจฉัยแยกจากญาติในสกุลเดียวกันที่ช่อห้อย** (§8) |
| **ก้านช่อ** | มักสั้นกว่าแกนช่อ (rachis) |
| **จำนวนดอก** | ประมาณ **20–50 ดอก** ต่อช่อ |
| **ขนาดดอก** | กว้างประมาณ **2–2.2 ซม.** |
| **สมมาตร** | สมมาตรด้านข้าง (zygomorphic) |
| **ดอกกลับหัว** | **resupinate** — รังไข่/ก้านดอกบิดราว 180° ทำให้ **กลีบปากที่ตามพัฒนาการอยู่ด้านบน มาอยู่ด้านล่าง** เป็นแท่นให้แมลงลงเกาะ |
| **วงกลีบ** | 3+3 แบบใบเลี้ยงเดี่ยว: **กลีบเลี้ยง (sepal) 3** · **กลีบดอก (petal) 3** โดยกลีบดอกกลางดัดแปลงเป็น **กลีบปาก (labellum/lip)** |
| **กลีบปาก** | รูปลิ่ม (wedge-shaped) โคนขาว ปลายสีม่วงคราม–น้ำเงินเข้ม · โคนกลีบมี **เดือย (spur)** สั้น แบน ส่วนปลายโค้งไปด้านหน้า |
| **สี** | กลีบทั้ง 5 สีขาว ปลายกลีบขลิบ/แต้มม่วงคราม · มีความหลากหลาย: **เขาแกะแดง** (อมม่วงแดง) · ฟอร์มน้ำเงิน · **เขาแกะเผือก** (ขาวล้วน) |
| **เกสร** | **เส้าเกสร (column / gynostemium)** — เกสรเพศผู้และยอดเกสรเพศเมียเชื่อมเป็นแท่งเดียว มี **ฝาอับเรณู (anther cap)** ที่ปลาย |
| **เรณู** | เรณูจับกันเป็นก้อน **(pollinia)** ไม่ฟุ้งกระจาย — แมลงพาไปทั้งก้อน · *จำนวน pollinia ของสกุลนี้ เอกสารระบุไม่ตรงกัน (2 หรือ 4 จับเป็น 2 คู่) — ยังไม่ยืนยัน* |
| **รังไข่** | **ใต้วงกลีบ (inferior ovary)** — "ก้านดอก" ที่เห็นจริง ๆ คือรังไข่ที่ยืดยาว |
| **กลิ่น/อายุดอก** | หอม · บานทนประมาณ **2 สัปดาห์** |
| **ฤดูออกดอก** | ฤดูร้อน–ต้นฝน ประมาณ **เมษายน–กรกฎาคม** |

## 7. ผลและเมล็ด (Fruit & Seed) → [[fruit-seed-morphology]]

- ผลแบบ **แคปซูล (capsule)** แห้งแตก ตามแบบวงศ์กล้วยไม้
- **เมล็ดเล็กมากคล้ายผงฝุ่น** จำนวนมหาศาลต่อผล · **ไม่มีเอนโดสเปิร์ม**
- การงอกในธรรมชาติต้องอาศัย **ราไมคอร์ไรซา (mycorrhiza)** ป้อนอาหารในระยะแรก → เป็นเหตุผลที่การขยายพันธุ์เชิงการค้าใช้ **การเพาะเมล็ดในอาหารวุ้น (in vitro)**
- **ผลต่อการอนุรักษ์**: ประชากรในธรรมชาติทดแทนตัวเองได้ช้า การเก็บจากป่าจึงกระทบเร็ว (§9)

## 8. แยกจากญาติในสกุลเดียวกัน (Diagnostic key)

| ชนิด | ช่อดอก | ใบ | จุดสังเกตเร็ว |
|------|--------|-----|----------------|
| **เขาแกะ** *R. coelestis* | **ตั้งขึ้น** ทรงกระบอกสั้น แน่น | บางกว่า โค้งสลับซ้าย-ขวาชัด | ช่อตั้ง + ปลายกลีบม่วงคราม |
| **ช้างกระ** *R. gigantea* | **ห้อยลง** | ใหญ่ หนากว่า | ช่อห้อย ดอกขาวประจุดม่วง |
| **ไอยเรศ (พวงมาลัย)** *R. retusa* | **ห้อยลง ยาวเป็นสาย** | ยาว หนา | ช่อห้อยยาวคล้ายพวงมาลัย |

> **กฎง่าย**: ในสกุล *Rhynchostylis* ของไทย — **ช่อตั้ง = เขาแกะ · ช่อห้อย = ช้างกระ/ไอยเรศ**

## 9. Layer U — การใช้ประโยชน์

- **ไม้ประดับ / ไม้ตัดดอก** — ดอกดก บานทน มีกลิ่นหอม จึงมีศักยภาพเป็นไม้ตัดดอก
- **พ่อ-แม่พันธุ์ลูกผสม** — ใช้ผสมข้ามกับกลุ่มแวนด้า/ช้าง เพื่อถ่ายทอดสีน้ำเงิน-ม่วงและลักษณะช่อตั้ง
- **การอนุรักษ์ (Conserving)** — กล้วยไม้ทุกชนิดอยู่ใน **CITES บัญชี 2 (Appendix II)** การค้าระหว่างประเทศต้องมีใบอนุญาต · แรงกดดันหลักคือการเก็บต้นจากป่า → เชื่อมกับ Botany Literacy ระดับที่ 5

## 10. Layer T — มุมแผนไทย → [[thai-herbal]]

- **ยังไม่พบหลักฐาน**: ไม่พบตำรับยาไทยหรือฐานข้อมูลเครื่องยาที่ระบุ "เขาแกะ" เป็นสมุนไพร/เครื่องยา
- โหนดนี้จึงเป็น **เคส Layer S + U ล้วน** — ใช้สอนได้ว่า *พืชที่มีคุณค่าไม่จำเป็นต้องเป็นสมุนไพรเสมอไป* คุณค่าอยู่ที่ระบบนิเวศ พันธุกรรม และเศรษฐกิจไม้ประดับ
- **ห้ามอนุมาน** สรรพคุณจากพืชสกุล/วงศ์เดียวกัน — ตามกติกาแหล่งอ้างอิงของโปรเจกต์ ([[reference-sources]])

## Misconceptions ที่พบบ่อย

| ความเข้าใจผิด | ข้อเท็จจริง |
|----------------|--------------|
| เขาแกะเป็นกาฝาก แย่งอาหารจากต้นไม้ | เป็น **พืชอิงอาศัย (epiphyte)** — เกาะอาศัยเฉย ๆ สร้างอาหารเองด้วยใบและปลายราก |
| รากอากาศสีขาว = รากแห้งตาย | สีขาวคือ **velamen แห้ง** — ได้น้ำแล้วกลายเป็นเขียวโปร่ง รากยังมีชีวิต |
| "เขาแกะ" ตั้งชื่อตามรูปดอก | ตั้งตาม **การเรียงใบโค้งสลับซ้าย-ขวา** ที่มองคล้ายเขาแกะ (§5) |
| กลีบปากอยู่ด้านล่างตามธรรมชาติ | อยู่ล่างเพราะ **ดอกกลับหัว (resupinate)** บิดราว 180° — กลไกเดียวกับดอกอัญชัน [[plant-anchan]] |
| กล้วยไม้สกุลนี้ช่อห้อยทุกชนิด | **เขาแกะช่อตั้ง** ต่างจากช้างกระและไอยเรศที่ช่อห้อย (§8) |
| เก็บจากป่ามาปลูกได้ ไม่เสียหายอะไร | กล้วยไม้อยู่ใน **CITES Appendix II** และเมล็ดงอกเองในธรรมชาติได้ยากมาก (§7, §9) |

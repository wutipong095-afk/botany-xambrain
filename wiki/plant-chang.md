# จั๋ง (Thai lady palm) — สัณฐานวิทยาระดับชนิด 🌐

## สาระสำคัญ

จั๋งเป็น **ปาล์มแตกกอขนาดเล็กในวงศ์ปาล์ม (Arecaceae)** — เป็น **พืชใบเลี้ยงเดี่ยว (monocot) ตัวที่สองของชุด monograph** ต่อจากกล้วยไม้เขาแกะ ([[plant-khao-kae]] M7) และเป็นคู่หูในไฟล์เดียวกับสุพรรณิการ์ ([[plant-supphannika]]) เพื่อเทียบ **dicot ↔ monocot**

จุดเรียน 3 เรื่องของ monocot ที่เห็นชัดในจั๋ง:

1. **แผนผังดอกวง 3 (3-merous)** — กลีบเลี้ยง 3 · กลีบดอก 3 · เกสรเพศผู้ 6 · คาร์เพล 3 → ลักษณะดอก monocot ตรงแบบ
2. **เส้นใบขนาน (parallel venation) + ไม่มีรากแก้ว + แตกกอ (clumping)** — กลุ่มลักษณะ monocot คลาสสิก
3. **ใบประกอบรูปพัด (palmate/fan leaf)** ของปาล์มกลุ่ม fan palm — ตัดกับใบ **แฉกฝ่ามือ (lobed)** ของสุพรรณิการ์ → สอนความต่าง "ประกอบ (compound)" กับ "แฉก (lobed)"

## 1. Naming

| หัวข้อ | ข้อมูล |
|--------|--------|
| **ชื่อวิทยาศาสตร์** | *Rhapis subtilis* Becc. |
| **วงศ์** | Arecaceae (Palmae) · อันดับ Arecales — **พืชใบเลี้ยงเดี่ยว (monocot)** |
| **ชื่อไทย/พื้นเมือง** | จั๋ง · จั๋งไทย · ปาล์มหวาย |
| **ชื่อสามัญ** | Dwarf lady palm · Thai lady palm |
| **รากศัพท์** | *Rhapis* จากกรีก *rhapis* = "เข็ม/ก้านเรียว" (ลำต้นเรียว) · *subtilis* = "เรียวบาง/ละเอียด" |

> **หมายเหตุ taxonomy**: ใบงานระบุ Class เป็น Equisetopsida (ตามระบบ WFO ที่จัดพืชมีท่อลำเลียงทั้งหมดไว้ชั้นนี้) — สาระสำคัญคือจั๋งเป็น **พืชใบเลี้ยงเดี่ยว (monocot)** อันดับ Arecales → ดู [[plant-taxonomy]]

## 2. นิสัยการเจริญ (Habit)

- **ปาล์มแตกกอ (clumping palm)** ขนาดเล็ก สูง ~3 ม. อายุหลายปี
- แตกหน่อจาก **ไหลใต้ดิน (rhizome)** เกิดเป็นกอหลายลำ — ต่างจากปาล์มลำเดี่ยว (เช่น หมากเขียว)

## 3. ราก (Root) → [[root-morphology]]

- **รากฝอย (fibrous root) — ไม่มีรากแก้ว** ตามแบบพืชใบเลี้ยงเดี่ยว → จุดตัดสำคัญกับสุพรรณิการ์ ([[plant-supphannika]]) ที่มีรากแก้ว (dicot)

## 4. ลำต้น (Stem) → [[stem-morphology]]

- ลำเรียวคล้ายไผ่ เส้นผ่านศูนย์กลาง 1–2 ซม. มีข้อปล้อง · **เส้นใย/กาบใบเก่าสีน้ำตาลหุ้ม**
- ไม่มียาง · หลายลำต่อกอ

## 5. ใบ (Leaf) → [[leaf-morphology]]

- **ใบประกอบรูปพัด (palmate/fan leaf)** — แผ่นใบแยกเป็นใบย่อยลึกเกือบถึงโคน ~2–11 ใบย่อย
- ใบย่อยรูปแคบ–รูปใบหอก ปลายเรียวมักมีรอยหยัก/ปลายตัด · **เส้นใบเรียงขนาน (parallel venation)** · ก้านใบยาวเรียวไม่มีหนาม ไม่มีหูใบ
- **จุดเทียบสำคัญกับสุพรรณิการ์**: จั๋ง = ใบ **ประกอบ (แยกเป็นใบย่อยจริง)** เส้นใบขนาน · สุพรรณิการ์ = ใบเดี่ยว **แฉก (lobed)** เส้นใบฝ่ามือ → คำว่า "ฝ่ามือ" ใช้ได้ทั้งคู่แต่คนละความหมาย

## 6. ดอก (Flower) → [[flower-morphology]]

| หัวข้อ | ลักษณะ |
|--------|---------|
| **ตำแหน่ง/ช่อ** | ออกระหว่างกาบใบ · ช่อแยกแขนง (panicle) |
| **เพศดอก** | **ดอกแยกเพศ (dioecious)** — ต้นเพศผู้/เพศเมียแยกกัน · ดอกเล็ก |
| **กลีบเลี้ยง** | **3 กลีบ** (โคนเชื่อม) |
| **กลีบดอก** | **3 กลีบ เชื่อมเป็นหลอด ปลายแยก** |
| **เกสรเพศผู้** | **6 อัน** (ในดอกเพศผู้) |
| **เกสรเพศเมีย/รังไข่** | รังไข่เหนือวงกลีบ **3 คาร์เพล · 1 ออวุล/คาร์เพล** |

> **จุดเรียนสำคัญ**: ดอกจั๋งเป็น **วง 3 (3-merous)** เต็มรูป (3+3+6+3) = แผนผังดอก monocot มาตรฐาน · ตัดกับดอกสุพรรณิการ์ที่เป็น **วง 5 + เกสรจำนวนมาก** (dicot) — เทียบสองดอกในไฟล์เดียวเห็น merosity ต่างกันชัด

## 7. ผลและเมล็ด (Fruit & Seed) → [[fruit-seed-morphology]]

- ผล **มีเนื้อ (berry)** ทรงกลมเล็ก ยาว ~6–9.4 มม. · สีขาวเมื่อแก่ · โดยทั่วไป **1 เมล็ดต่อผล**
- เมล็ดมี **เอนโดสเปิร์ม (endosperm)** หล่อเลี้ยงต้นอ่อน — ลักษณะเมล็ดปาล์มทั่วไป

## 8. Layer U — การใช้ประโยชน์

- **ไม้ประดับยอดนิยม**: ปลูกในกระถางในอาคาร/ที่ร่ม ทนร่มได้ดีมาก · ฟอกอากาศ
- **ความเชื่อ**: คนไทยนิยมปลูก "จั๋ง" เป็นไม้มงคล (ชื่อพ้อง "มั่งคั่ง/ค้ำจุน")

## 9. Layer T — มุมภูมิปัญญา → [[thai-herbal]]

- จั๋งใช้เป็นไม้ประดับ/ไม้มงคลเป็นหลัก · การใช้เป็นยาไม่เด่น
- คุณค่าเชิงเรียน: เป็นตัวแทน **ปาล์ม (monocot)** ในชุด — เทียบโครงสร้าง monocot กับกล้วยไม้เขาแกะ ([[plant-khao-kae]])

## Misconceptions ที่พบบ่อย

| ความเข้าใจผิด | ข้อเท็จจริง |
|----------------|--------------|
| จั๋งเป็นไผ่ (ลำคล้ายไผ่) | เป็น **ปาล์ม (Arecaceae)** ไม่ใช่หญ้าไผ่ — ดอก/ผล/ใบพัดต่างกันสิ้นเชิง |
| ใบพัดของจั๋ง = ใบเดี่ยวแฉก | เป็น **ใบประกอบรูปพัด** แยกเป็นใบย่อยจริง (§5) — ต่างจากใบแฉกของสุพรรณิการ์ |
| ปาล์มมีรากแก้วเหมือนไม้ต้นทั่วไป | monocot มี **รากฝอย ไม่มีรากแก้ว** (§3) |
| จั๋งมีดอกวง 5 เหมือนไม้ดอกทั่วไป | ดอก **วง 3** (3+3+6+3) ตามแบบ monocot (§6) |
| จั๋งลำเดียวโตเดี่ยว | จั๋ง **แตกกอ** หลายลำจากไหลใต้ดิน (§2) |

## ภาคผนวก — ตารางเทียบ dicot ↔ monocot (สุพรรณิการ์ ↔ จั๋ง)

| ลักษณะ | **สุพรรณิการ์** ([[plant-supphannika]]) | **จั๋ง** (โหนดนี้) |
|--------|------------------|--------|
| กลุ่มใหญ่ | **ใบเลี้ยงคู่ (dicot)** | **ใบเลี้ยงเดี่ยว (monocot)** |
| วงศ์/อันดับ | Bixaceae / Malvales | Arecaceae / Arecales |
| ราก | **รากแก้ว** | **รากฝอย** (แตกกอ) |
| การเรียง/เส้นใบ | เวียนสลับ · **เส้นใบฝ่ามือ (ร่างแห)** | เวียนที่ยอด · **เส้นใบขนาน** |
| ใบ | **ใบเดี่ยวแฉกฝ่ามือ (lobed)** | **ใบประกอบรูปพัด (compound)** |
| ดอก (merosity) | **วง 5** + เกสรจำนวนมาก | **วง 3** (3+3+6+3) |
| สมมาตรดอก | actinomorphic | actinomorphic (เล็ก แยกเพศ) |
| ผล | แคปซูลแตก · เมล็ดมีปุยฝ้าย | berry · 1 เมล็ด |

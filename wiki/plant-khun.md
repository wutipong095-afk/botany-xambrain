# คูน / ราชพฤกษ์ (Golden shower) — สัณฐานวิทยาระดับชนิด 🌐

## สาระสำคัญ

คูน (ราชพฤกษ์) เป็น **ไม้ต้นในวงศ์ถั่ว (Fabaceae)** เหมือนอัญชัน แคบ้าน และเถาวัลย์เปรียง — **แต่คนละวงศ์ย่อย** คูนอยู่วงศ์ย่อย **Caesalpinioideae** ไม่ใช่ Faboideae/Papilionoideae จึงเป็นเคสเรียน "วงศ์เดียวกันแต่หน้าตาดอก-ผลต่างกันสิ้นเชิง" ที่ดีที่สุดในชุด monograph นี้

จุดเรียน 3 เรื่องที่ทำให้คูนเป็นคู่เทียบสำคัญของ [[plant-anchan]] · [[plant-khae-ban]] · [[plant-thaowan-priang]]:

1. **ดอกไม่ใช่รูปดอกถั่ว (non-papilionaceous)** — กลีบดอก 5 กลีบสีเหลืองแผ่กางเกือบเท่ากัน ไม่มีกลีบกลาง/กลีบปีก/กลีบกระโดงแบบวงศ์ย่อย Faboideae → สอนว่า "Fabaceae ไม่ได้มีดอกถั่วทุกชนิด"
2. **ฝักไม่แตก (indehiscent)** — ฝักทรงกระบอกยาวแข็ง สีดำเมื่อแก่ ไม่แตกตามตะเข็บ ต่างจากฝักอัญชัน/แคบ้านที่แตกดีดเมล็ด → เคสเทียบชนิดผลแบบ legume ที่ **แตก vs ไม่แตก**
3. **เกสรเพศผู้ขนาดไม่เท่ากัน (heteromorphic stamens)** — สะพาน S → ชีววิทยาการผสมเกสร (เกสรชุด "ล่อ" vs ชุด "ผสม")

และเป็นสะพาน Layer S → U → T ที่แข็งแรง: **เนื้อในฝักสีดำ** ใช้เป็นยาระบายอ่อนตามตำราไทย · คูนคือ **ต้นไม้/ดอกไม้ประจำชาติไทย** (ราชพฤกษ์) สีเหลืองอร่ามเป็นสัญลักษณ์

## 1. Naming

| หัวข้อ | ข้อมูล |
|--------|--------|
| **ชื่อวิทยาศาสตร์** | *Cassia fistula* L. |
| **วงศ์** | Fabaceae (Leguminosae) |
| **วงศ์ย่อย** | Caesalpinioideae — **ต่างจาก [[plant-anchan]] / [[plant-khae-ban]] / [[plant-thaowan-priang]] ที่อยู่วงศ์ย่อย Faboideae** |
| **ชื่อไทย/พื้นเมือง** | คูน · คูณ · ราชพฤกษ์ (ราชการ) · ลมแล้ง (เหนือ) · กุเพยะ (กะเหรี่ยง) |
| **ชื่อสามัญ** | Golden shower · Indian laburnum · Purging cassia |
| **รากศัพท์** | *fistula* (ละติน) = "ท่อ/หลอด" หมายถึงฝักทรงกระบอกยาวกลวงคล้ายท่อ — เป็นลักษณะวินิจฉัยที่ผูกอยู่ในชื่อชนิด |

> **หมายเหตุ taxonomy**: ระบบเดิมแยก Caesalpiniaceae เป็นวงศ์ต่างหาก · ปัจจุบัน (APG) รวมเป็นวงศ์ย่อย **Caesalpinioideae** ในวงศ์ Fabaceae → ดู [[plant-taxonomy]]

## 2. นิสัยการเจริญ (Habit)

- ไม้ต้นขนาดกลาง **ผลัดใบ** สูง 10–20 ม. ทรงพุ่มกลม แตกกิ่งแผ่กว้าง
- ทิ้งใบช่วงแล้ง แล้ว **ออกดอกพร้อมกันทั้งต้นเป็นสีเหลืองอร่าม** ช่วงปลายแล้ง–ต้นฝน (มี.ค.–พ.ค.) — จุดเด่นที่ทำให้เป็นไม้ประดับและสัญลักษณ์ประจำชาติ

## 3. ราก (Root) → [[root-morphology]]

- ระบบ **รากแก้ว (taproot)** พร้อมรากแขนง
- อยู่วงศ์ถั่ว แต่รายงานการตรึงไนโตรเจน/ปมรากใน *Cassia fistula* ไม่เด่นชัดเท่ากลุ่ม Faboideae (อัญชัน/แคบ้าน) — เป็นจุดสังเกตว่าลักษณะ "ปมราก" ไม่ใช่ของวงศ์ถั่วทุกชนิด

## 4. ลำต้น (Stem) → [[stem-morphology]]

- ลำต้นตั้งตรง เปลือกค่อนข้างเรียบเมื่ออ่อน · แก่แล้วแตกเป็นสะเก็ด/ร่องตื้น
- สีเปลือกน้ำตาล–เทาอมดำ · กิ่งอ่อนเขียวอมเทา กิ่งแก่น้ำตาล
- **ไม่มีน้ำยางสีขาวเด่นชัด** (ใช้แยกจากไม้ต้นวงศ์ที่มียาง เช่น หม่อน [[plant-mon]] Moraceae)

## 5. ใบ (Leaf) → [[leaf-morphology]]

- **ใบประกอบแบบขนนกชั้นเดียว ปลายคู่ (paripinnate)** เรียงสลับ
- ใบย่อย **3–8 คู่** เรียงตรงข้ามกันเป็นคู่ · รูปไข่–รูปไข่แกมขอบขนาน (ovate–elliptic)
- ปลายแหลมมน–มน · โคนมน–สอบ · ขอบเรียบ (entire) · เส้นใบร่างแหแบบขนนก
- **จุดเทียบ**: ใบขนนกปลายคู่เหมือน [[plant-khae-ban]] แต่คูนมีใบย่อยน้อยคู่และใบใหญ่กว่า

## 6. ดอก (Flower) → [[flower-morphology]]

| หัวข้อ | ลักษณะ |
|--------|---------|
| **การออกดอก** | ช่อกระจะ (raceme) ยาว **ห้อยลง** ตามซอกใบ/ปลายกิ่ง ดอกจำนวนมาก |
| **สี** | เหลืองสดทั้งช่อ |
| **รูปดอก** | **ไม่ใช่รูปดอกถั่ว** — กลีบดอก 5 กลีบสีเหลืองแผ่กางเกือบเท่ากัน (สมมาตรด้านข้างเพียงเล็กน้อย) |
| **กลีบเลี้ยง** | 5 กลีบ แยกจากกัน |
| **เกสรเพศผู้** | **10 อัน ขนาดไม่เท่ากัน (heteromorphic)** — โดยทั่วไป 3 อันยาวก้านโค้งรูปตัว S (ทำหน้าที่ผสมจริง) + 4 อันกลาง + 3 อันสั้น/เกสรเทียม (ล่อแมลง) |
| **เกสรเพศเมีย** | 1 อัน · รังไข่ **เหนือวงกลีบ (superior)** · ก้านเกสรยาวโค้ง |
| **เพศ/ความสมบูรณ์** | ดอกสมบูรณ์เพศ (bisexual) + ดอกสมบูรณ์ (complete) |
| **การผสมเกสร** | ผึ้งขนาดใหญ่สั่นเกสร (buzz pollination) — สัมพันธ์กับเกสรสองชุด |

> **จุดเรียนสำคัญ**: ดอกคูนกับดอกอัญชัน/แคบ้าน = วงศ์เดียวกัน (Fabaceae) แต่ **สถาปัตยกรรมดอกคนละแบบ** เพราะต่างวงศ์ย่อย → ใช้สอนว่าการจัดวงศ์ย่อยดูจากโครงดอก (ดอกถั่ว vs ดอกแผ่กาง)

## 7. ผลและเมล็ด (Fruit & Seed) → [[fruit-seed-morphology]]

- ผลแบบ **ฝัก (legume)** แต่ **ทรงกระบอกยาว แข็ง ไม่แบน** ยาว 20–60 ซม. (ชื่อ *fistula* = ท่อ)
- **ไม่แตกเมื่อแก่ (indehiscent)** — ต่างจากฝักอัญชัน/แคบ้านที่แตกดีดเมล็ด → เคสเทียบ legume แตก vs ไม่แตก
- ภายในมีเมล็ดจำนวนมากเรียงตามขวาง แบ่งเป็นห้อง ๆ ด้วย **เนื้อเยื่อสีดำเหนียว (pulp)** — เนื้อในนี้คือส่วนที่ใช้เป็นยาระบาย (§9)
- เมล็ดแบน รูปรี–เกือบกลม สีน้ำตาล · กระจายโดยสัตว์

## 8. Layer U — การใช้ประโยชน์

- **ไม้ประดับ/สัญลักษณ์**: ดอกเหลืองทั้งต้น ปลูกริมถนน สวนสาธารณะ · **ต้นไม้ประจำชาติไทย** และ **ดอกไม้ประจำชาติ** (ดู §9)
- **เนื้อในฝัก (pulp)**: ยาระบายอ่อน — ใช้ในตำรับพื้นบ้านและมีการศึกษาเภสัชวิทยา
- **เนื้อไม้**: แข็ง ใช้ทำเสา เครื่องมือเกษตร
- **ย้อม/ฟอกหนัง**: เปลือกมีแทนนิน

## 9. Layer T — มุมแผนไทยและวัฒนธรรม → [[thai-herbal]] · [[herbal-taste-9]]

- **ราชพฤกษ์ = สัญลักษณ์ชาติ**: ดอกไม้ประจำชาติไทย · สีเหลืองคือสีวันจันทร์/สีมงคล · ปลูกในพระราชพิธีและงานมงคล
- **เนื้อในฝัก (คูน)**: ตำราไทยจัดเป็น **ยาระบาย/ยาถ่ายอ่อน** (รสหวานเอียน) แก้ท้องผูก ขับพยาธิ — กลุ่มเดียวกับ *Cassia* อื่น (มะขามแขก *Senna alexandrina* เดิม *Cassia*)
- **ดอก/เปลือก**: ตำรับพื้นบ้านใช้แก้ไข้ แก้โรคผิวหนังบางกลุ่ม
- **ข้อควรระวัง**: ฤทธิ์ระบาย — ใช้เกินขนาดทำให้ถ่ายมาก/ปวดมวนท้อง · หญิงตั้งครรภ์ควรเลี่ยง

## Misconceptions ที่พบบ่อย

| ความเข้าใจผิด | ข้อเท็จจริง |
|----------------|--------------|
| คูนมีดอกรูปดอกถั่วเพราะอยู่วงศ์ถั่ว | อยู่วงศ์ย่อย **Caesalpinioideae** ดอก **แผ่กาง 5 กลีบ ไม่ใช่ดอกถั่ว** (§6) |
| ฝักคูนแตกดีดเมล็ดเหมือนฝักอัญชัน | ฝักคูน **ไม่แตก (indehiscent)** เป็นท่อกระบอกแข็ง (§7) |
| คูน = ชัยพฤกษ์ = กัลปพฤกษ์ (ต้นเดียวกัน) | คนละชนิด: คูน/ราชพฤกษ์ = *C. fistula* (เหลือง) · ชัยพฤกษ์ = *C. javanica* (ชมพู) · กัลปพฤกษ์ = *C. bakeriana* (ชมพูอ่อน) — ดูชุด 21 ชนิด |
| "ต้นคูน" คือบอน/ต้นคูน (พืชล้มลุกริมน้ำ) | คนละพืช — บอน/คูน (*Colocasia/Alocasia*) เป็นพืชล้มลุกวงศ์ Araceae |
| เกสรเพศผู้ทุกอันเท่ากัน | เกสร **ขนาดไม่เท่ากัน 3 ชุด** — เกี่ยวกับชีววิทยาการผสมเกสร (§6) |

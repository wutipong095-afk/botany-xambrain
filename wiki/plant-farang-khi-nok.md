# ฝรั่งขี้นก (Guava) — สัณฐานวิทยาระดับชนิด 🌐

## สาระสำคัญ

ฝรั่งขี้นกเป็น **ไม้ต้นในวงศ์ Myrtaceae (วงศ์ชมพู่/หว้า/ยูคาลิปตัส)** — วงศ์ใหม่ของชุด monograph "ฝรั่งขี้นก" คือ **ฝรั่งพันธุ์ป่า/กึ่งป่า** (ชนิดเดียวกับฝรั่งกิน *Psidium guajava*) ที่ผลเล็กและ **นกกินแล้วถ่ายเมล็ดกระจาย** จึงชื่อ "ขี้นก"

จุดเรียน 3 เรื่องเด่นของ Myrtaceae:

1. **เกสรเพศผู้จำนวนมากเป็นพู่ (numerous stamens)** — ลักษณะเด่นของวงศ์ (เหมือนชมพู่/ยูคา) → เทียบ "เกสรจำนวนมาก" กับสุพรรณิการ์ ([[plant-supphannika]]) แต่คนละวงศ์
2. **ใบเดี่ยวเรียงตรงข้าม มีต่อมน้ำมัน (oil glands) + เส้นใบขอบใน (intramarginal vein)** — ส่องใบมีจุดใส หอมเมื่อขยี้
3. **เปลือกลอกเป็นแผ่น (peeling bark)** — เหมือนตะแบก ([[plant-tabaek]]) แต่คนละวงศ์ → เปลือกลอกเป็นลักษณะที่พบข้ามวงศ์

| **ชื่อไทย/พื้นเมือง** | ฝรั่งขี้นก · ฝรั่งป่า · ฝรั่ง · ยามู (ใต้) |
| **ชื่อสามัญ** | Guava |
| **ที่มาชื่อ "ขี้นก"** | พันธุ์ป่า/กึ่งป่าผลเล็ก · **นกกินผลแล้วถ่ายเมล็ด** ทำให้แพร่กระจายเอง (zoochory) |

## 2–5. วิสัย/ราก/ลำต้น/ใบ

- ไม้ต้นเล็ก · **เปลือกลอกเป็นแผ่น** · **กิ่งอ่อนเป็นเหลี่ยม (4 เหลี่ยม) มีขนขาว** — จุดสังเกตของ *Psidium* → [[stem-morphology]]
- **ใบเดี่ยว เรียงตรงข้าม** เนื้อหนาหยาบ · **เส้นขอบใน (intramarginal vein)** และ **ต่อมน้ำมัน** (ส่องใบเห็นจุดใส หอมเมื่อขยี้) — ลักษณะเด่น Myrtaceae → [[leaf-morphology]]

## 6. ดอก (Flower) → [[flower-morphology]]

- ดอกขาว ออกเดี่ยว/กระจุกที่ซอกใบ · กลีบดอก 4–5 ร่วงง่าย
- **เกสรเพศผู้จำนวนมากเป็นพู่สีขาว** = ลักษณะเด่นวงศ์ Myrtaceae · **รังไข่ใต้/กึ่งใต้วงกลีบ** (ผลจึงมีรอยกลีบเลี้ยงที่ปลาย)

> **จุดเทียบ**: "เกสรจำนวนมาก" พบทั้งฝรั่ง (Myrtaceae) และสุพรรณิการ์ ([[plant-supphannika]] Bixaceae) — แต่ฝรั่งเกสรอิสระเป็นพู่ ส่วนสุพรรณิการ์อับเรณูเปิดรู (poricidal) → เกสรมากไม่ได้แปลว่าวงศ์เดียวกัน

## 7. ผล (Fruit) → [[fruit-seed-morphology]]

- **ผลสด (berry)** กลม–รูปไข่ · ปลายมีรอยกลีบเลี้ยงติด (จากรังไข่ใต้วงกลีบ) · **เมล็ดแข็งจำนวนมาก** ในเนื้อ · ฝรั่งขี้นกผลเล็กและเมล็ดเยอะกว่าพันธุ์ปลูก

## 8. Layer U — การใช้ประโยชน์

- **อาหาร**: ผลกินสด · **วิตามินซีสูงมาก** · ฝรั่งขี้นกนิยมทำเป็นต้นตอเสียบพันธุ์ปลูก
- **ยอด/ใบอ่อน**: กินเป็นผักแกล้ม

## 9. Layer T — มุมแผนไทย → [[thai-herbal]] · [[herbal-taste-9]]

- **ใบฝรั่งรสฝาด (แทนนิน)** → กลุ่มสมาน **แก้ท้องเสีย/ท้องร่วง** (ใบอ่อนเคี้ยว/ต้ม) — เป็นสมุนไพรพื้นบ้านที่ใช้แพร่หลายและมีงานวิจัยรองรับพอควร
- ผลดิบรสฝาด · ผลสุกรสหวาน → รสยาต่างกันตามระยะ ([[herbal-taste-9]])

## Misconceptions

| ความเข้าใจผิด | ข้อเท็จจริง |
|----------------|--------------|
| ฝรั่งขี้นกเป็นคนละชนิดกับฝรั่งกิน | **ชนิดเดียวกัน** *Psidium guajava* · "ขี้นก" = พันธุ์ป่าผลเล็กที่นกกระจายเมล็ด |
| เกสรพู่มาก = วงศ์เดียวกับสุพรรณิการ์ | เกสรจำนวนมากพบหลายวงศ์ · ฝรั่ง = **Myrtaceae** (ต่อมน้ำมัน · เส้นขอบใน) (§6) |
| เปลือกลอกเป็นแผ่น = ต้องเป็นตะแบก | เปลือกลอกพบข้ามวงศ์ · ฝรั่ง (Myrtaceae) ↔ ตะแบก (Lythraceae) (§4) |
| ผลฝรั่งมีรอยที่ปลาย = ผลเสีย | เป็น **รอยกลีบเลี้ยงติดผล** จากรังไข่ใต้วงกลีบ (§7) |

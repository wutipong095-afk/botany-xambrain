# น้ำใจใคร่ (Olax psittacorum) — สัณฐานวิทยาระดับชนิด 🌐

## สาระสำคัญ

น้ำใจใคร่เป็น **ไม้พุ่มรอเลื้อยในวงศ์ OLACACEAE** — **วงศ์ใหม่ตัวที่สองของชุด monograph** (ต่อจากส้มลม/Apocynaceae) จึงเป็นเคสเรียนสัณฐานวิทยาที่เปิดจุดใหม่ 3 เรื่อง:

1. **แผนผังดอกแบบ 3 (3-merous corolla) ที่ไม่ลงตัวกับกลีบเลี้ยง** — กลีบดอก **3 กลีบ** + เกสรเพศผู้ **3 อัน** + ยอดเกสรแยก **3 แฉก** แต่กลีบเลี้ยง **5 กลีบเชื่อมเป็นรูปถ้วย** → สอนการ "นับจำนวนชิ้นส่วนดอก (merosity)" และสังเกตว่าวงกลีบเลี้ยง/กลีบดอกไม่จำเป็นต้องเท่ากัน
2. **ผลเดี่ยวทรงกลม เมล็ดเดียว (1-seeded drupe/berry)** — ชนิดผลใหม่ที่ต่างจากฝัก legume (คูน/อัญชัน) และ follicle (ส้มลม) → เติมสเปกตรัม "ชนิดผล" ให้ครบขึ้น
3. **หนึ่งชนิด หลายสิบชื่อท้องถิ่น** — น้ำใจใคร่ · นางจุม/นางชม (เหนือ) · กระทกรก · ลูกไข่แลน · เสาะเทาะ (ใต้) ฯลฯ → เคสสอนว่าทำไม **ชื่อวิทยาศาสตร์ (binomial)** จึงจำเป็น (Botany Literacy ระดับ Naming) — ดู [[plant-taxonomy]]

## 1. Naming

| หัวข้อ | ข้อมูล |
|--------|--------|
| **ชื่อวิทยาศาสตร์** | *Olax psittacorum* (Lam.) Vahl |
| **วงศ์** | Olacaceae |
| **สกุล** | *Olax* |
| **ผู้ตั้งชื่อ** | วงเล็บ (Lam.) = Lamarck ตั้งชื่อเดิม · Vahl = ผู้ย้าย/แก้ชื่อภายหลัง — สอนความหมายของ **วงเล็บในชื่อผู้ตั้งชื่อ (basionym author)** |
| **ชื่อไทย/พื้นเมือง** | น้ำใจใคร่ · นางจุม · นางชม (เหนือ) · กระทกรก · กระทอกอก · ลูกไข่แลน · เสาะเทาะ (ใต้) · กระเด๊าะ · อาลิง (มลายู) |
| **รากศัพท์** | *psittacorum* จากละติน *psittacus* = "นกแก้ว" |

> **หมายเหตุ taxonomy**: Olacaceae เป็นวงศ์ไม้ต้น/ไม้พุ่มเขตร้อน · หลายสกุลในวงศ์นี้เป็น **กึ่งกาฝากที่ราก (root hemiparasite)** — เป็นลักษณะระดับวงศ์ที่น่าตรวจสอบในภาคสนาม (ข้อมูลระดับชนิดของน้ำใจใคร่ยังไม่ยืนยันในใบงาน) → ดู [[plant-taxonomy]]

## 2. นิสัยการเจริญ (Habit)

- **ไม้พุ่มรอเลื้อย (scrambling shrub)** สูง 2–5 ม. — ทรงกึ่งพุ่มกึ่งเลื้อย พาดกิ่งกับพืชข้างเคียง
- ต่างจากส้มลม ([[plant-somlom]]) ที่เป็นไม้เถาเลื้อยพันแท้ ๆ

## 3. ราก (Root) → [[root-morphology]]

- ระบบ **รากแก้ว (taproot)** ตามแบบพืชใบเลี้ยงคู่

## 4. ลำต้น (Stem) → [[stem-morphology]]

- เปลือกสีเขียวเข้ม–เทาอมน้ำตาล แตกเป็นแนวยาว
- **ไม่มียาง** — ตัดกับส้มลม (Apocynaceae) ที่มีน้ำยางขาว → ย้ำว่า "มี/ไม่มียาง" ใช้แยกวงศ์ได้

## 5. ใบ (Leaf) → [[leaf-morphology]]

- **ใบเดี่ยว (simple) เรียงสลับ (alternate)** — ต่างจากส้มลมที่ใบเดี่ยว**เรียงตรงข้าม** → คู่เทียบการเรียงใบภายในกลุ่มไม้เถา/พุ่มใบเดี่ยว
- รูปรี–รูปหอก กว้าง 1–4 ซม. ยาว 2–10 ซม. · ปลายแหลม โคนมน ขอบเรียบ
- เนื้อใบค่อนข้างหนา · **หลังใบเรียบมัน ท้องใบมีขนนุ่ม** (จุดสังเกตด้วยการลูบ)

## 6. ดอก (Flower) → [[flower-morphology]]

| หัวข้อ | ลักษณะ |
|--------|---------|
| **การออกดอก** | ช่อกระจุก (cyme/fascicle) 1–3 ช่อต่อซอกใบ |
| **สี/ขนาด** | ดอกเล็ก สีขาว กว้าง ~1.5 มม. ยาว 7–8 มม. |
| **กลีบเลี้ยง** | **5 กลีบ เชื่อมเป็นรูปถ้วย (cupular calyx)** |
| **กลีบดอก** | **3 กลีบ สีขาว** |
| **เกสรเพศผู้** | **3 อัน** อับเรณูรูปขอบขนาน |
| **เกสรเพศเมีย** | ยอดเกสรแยก **3 แฉก** · รังไข่รูปไข่ |

> **จุดเรียนสำคัญ (merosity)**: ดอกน้ำใจใคร่มีวง **3** ชัด (กลีบดอก 3 · เกสรผู้ 3 · ยอดเกสร 3 แฉก) **แต่กลีบเลี้ยง 5** เป็นถ้วย — ใช้ฝึกนับจำนวนชิ้นส่วนดอกและเห็นว่าจำนวนของแต่ละวงไม่จำเป็นต้องเท่ากัน · เทียบดอก 5 กลีบของวงศ์อื่นในชุด

## 7. ผลและเมล็ด (Fruit & Seed) → [[fruit-seed-morphology]]

- ผล **เดี่ยว ทรงกลม** กว้าง 0.5–1.5 ซม. — เป็นผลสด **เมล็ดเดียว (1-seeded)** (กลุ่ม drupe/berry) มีกลีบเลี้ยงรูปถ้วยรองอยู่ที่โคน
- ต่างจากผลหลายเมล็ดแบบฝัก (คูน/อัญชัน/แค) และ follicle (ส้มลม) → **ผลเมล็ดเดียว** มักกระจายโดยสัตว์ที่กินผล

> **เทียบชนิดผล 4 ชนิดในชุด**
>
> | ชนิด | ชนิดผล | จำนวนเมล็ด |
> |------|--------|------------|
> | **น้ำใจใคร่** | ผลกลมสด (drupe/berry) | **1** |
> | [[plant-somlom]] ส้มลม | follicle (ฝักคู่ แตก) | หลายเมล็ด |
> | [[plant-khun]] คูน | legume ทรงกระบอก ไม่แตก | มาก |
> | [[plant-anchan]] อัญชัน | legume แบน แตกดีด | 6–10 |

## 8. Layer U — การใช้ประโยชน์

- **ผักพื้นบ้าน**: ยอดอ่อน/ใบอ่อนกินได้ในบางท้องถิ่น (ลวก/แกง)
- **ไม้ใช้สอย/รั้วธรรมชาติ** ในพื้นที่ป่าละเมาะ

## 9. Layer T — มุมแผนไทยและข้อควรระวัง → [[thai-herbal]] · [[herbal-taste-9]]

- ตำรับพื้นบ้านหลายภาคใช้ราก/ต้น/ใบในกลุ่มแก้ไข้ แก้ร้อนใน (องค์ความรู้ท้องถิ่น — หลักฐานทางคลินิกยังจำกัด)
- **ความหลากหลายของชื่อท้องถิ่น** สะท้อนการใช้ที่กระจายหลายภาค → เป็นตัวอย่าง ethnobotany ที่ดีของ Layer T
- **ข้อควรระวัง**: ชื่อ "กระทกรก" ซ้ำกับพืชอื่น (ดู Misconceptions) — ก่อนใช้เป็นยา/อาหารต้องยืนยันชนิดจากลักษณะพฤกษศาสตร์ ไม่ใช่จากชื่อเรียก

## Misconceptions ที่พบบ่อย

| ความเข้าใจผิด | ข้อเท็จจริง |
|----------------|--------------|
| "กระทกรก" = น้ำใจใคร่เสมอ | ชื่อ **กระทกรก** ยังใช้เรียก **เสาวรสขน/รกช้าง (*Passiflora foetida*)** ซึ่งคนละวงศ์กัน — ต้องยืนยันด้วย *ชื่อวิทยาศาสตร์* |
| กลีบดอก 3 กลีบ = พืชใบเลี้ยงเดี่ยว | น้ำใจใคร่เป็น **ใบเลี้ยงคู่ (รากแก้ว · ใบร่างแห)** ที่บังเอิญมีกลีบดอกวง 3 — merosity ไม่ใช่เกณฑ์ตัดสิน monocot/dicot เพียงลำพัง |
| กลีบเลี้ยงต้องเท่าจำนวนกลีบดอก | ที่นี่กลีบเลี้ยง **5** แต่กลีบดอก **3** — คนละวง คนละจำนวนได้ (§6) |
| ผลมีหลายเมล็ดเหมือนฝัก | ผล **เมล็ดเดียว** ทรงกลม (§7) |
| ไม้เถา/พุ่มเลื้อยมียางทุกชนิด | น้ำใจใคร่ **ไม่มียาง** ต่างจากส้มลม (§4) |
